文件夹保险箱（FolderVault）：给文件夹加一道密码门

发表于2026-11-25|更新于2026-11-28|我的软件
|浏览量:

一个自写的 Windows 小工具：把文件夹”藏起来”，要用时输密码才打开。零依赖、免安装、可放 U 盘带走。**默认密码是 1111**，下载后建议尽快改成自己的。

先说清楚：它不是加密

这点必须放在最前面，免得误解：

它是”访问控制”，不是”文件加密”。 工具做的是把文件夹设为隐藏 + 系统属性，让它从资源管理器里消失；里面的文件本身一个字节都没加密。懂电脑的人关掉”隐藏受保护的操作系统文件”、或直接全盘搜索，仍然能找到。

所以它的定位很明确：

适合 ✅ 不适合 ❌
防家人、同事随手点开误翻 防有意窃取、防拆盘读取
临时藏一下私密文件夹 存真正敏感的资料

如果需要真加密，请用 7-Zip 的 AES-256 加密压缩包，或 VeraCrypt 加密卷。忘记本工具的密码无法找回（只存哈希，不可逆推），请记牢。

它能做什么

  • 双击即用：VBS 启动器，无黑色命令行窗口。
  • 密码门：首次运行设置密码（默认包已设为 1111），之后输对密码才能打开文件夹。
  • 多文件夹管理：可添加多个受保护文件夹，统一列在主界面，一键全部上锁。
  • 取消保护 / 改密码：都需验证，取消后文件夹恢复可见，里面文件不受影响。
  • 可携带：相对路径设计，整个文件夹拷到 U 盘、换台 Windows 电脑双击照样用。

技术小结

项目 方案
实现 PowerShell + .NET WinForms（Windows 自带，零依赖）
密码存储 SHA256 + 随机 salt，配置里不存明文
隐藏方式 置位 Hidden(2) + System(4) 文件属性
配置 vault.config（JSON，存哈希/salt/文件夹列表）

密码校验用的是 SHA256(salt + "|" + 密码)，与配置文件中的哈希比对。salt 为随机 GUID，所以同样的密码在不同安装里哈希也不同。

怎么用

  1. 下载下面的压缩包，解压到任意文件夹（建议整个文件夹一起留着，别只拷 FolderVault.ps1）。
  2. 双击 启动-文件夹保险箱.vbs，输入密码 **默认 1111**。
  3. 点「添加文件夹」，选中要藏的目录 —— 它会立刻从资源管理器消失。
  4. 想打开时：在列表里选中它，点「打开（需密码）」，输密码即可。
  5. 用完点「全部上锁」，重新藏回去。

建议：拿到后第一件事就是点「修改密码」，把默认的 1111 换成自己的。

配置文件 vault.config 里会记录你添加过的文件夹路径，把整个包发给别人前记得清掉（删除该文件会让你重设密码，但文件夹里的文件一个字节都不会丢；想立刻恢复可见，命令行执行 attrib -h -s "文件夹路径"）。

备用方案：一键显示所有文件夹

万一哪天忘了密码、或者主程序打不开，还有一个更简单的后路：直接把文件夹全部显示出来。

因为文件根本没加密，只是被”隐藏 + 系统”两个属性藏了起来，所以不需要密码 —— 读 vault.config 里的文件夹列表，逐个清掉这两个属性位就行。这比主程序更精准、更不易出错。

我做成了独立启动器，和主工具包分开，你可以按需单独拿取：想藏文件夹用原工具，想一键全显示用这个。两个互不干扰。

用法：下载下面两个文件，放在同一个文件夹里（最好直接放进「文件夹保险箱-完整包」，这样配置文件就近就能找到），双击 启动-一键显示所有文件夹.vbs，弹窗会告诉你显示了几个文件夹。找不到配置时它会按顺序找：启动器所在目录 → 桌面上的「文件夹保险箱-完整包」。
